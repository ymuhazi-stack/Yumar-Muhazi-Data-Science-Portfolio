# Customer Churn Analysis
# Overview
This project investigates customer churn using exploratory data analysis, feature engineering, machine learning and Power BI visualisation.

## Key Objectives
- Understand customer churn behaviour
- Identify key drivers of churn
- Evaluate machine learning models
- Develop stakeholder-focused dashboards
## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-Learn
- Power BI
## Models Evaluated
- Logistic Regression
- Random Forest
- SMOTE-Enhanced Random Forest
## Key Findings
- Lower engagement was associated with increased churn.
- Churned customers exhibited lower satisfaction scores.
- Payment failures were linked to churn risk.
- Tenure, CSAT score and monthly logins were among the strongest predictors.
